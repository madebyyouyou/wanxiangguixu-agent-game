本目录是《渡厄镇》三套随行系统（灵球 Agent）的全部 prompt 与对接资料。下面说明**每个文件干嘛、怎么加载、改的时候注意什么**。

## 二、怎么加载（最重要）

> **一个系统的完整 system prompt ＝ `Agent_System_Base.md` ＋ 玩家所选的那一份人格文件**（两段拼起来，整段作为 system prompt 传给模型）。

- 玩家选了雀舌 → 底座 + `Agent_System_1_QueShe.md`
- 选了乌有 → 底座 + `Agent_System_2_WuYou.md`
- 选了枢衡 → 底座 + `Agent_System_3_ShuHeng.md`

三套人格**互不加载、互不知晓**。底座里**不出现任何系统名字**，所以不会让某个系统"知道"另外两个的存在。

运行时每轮再喂"当前状态文本"（怎么拼见 `程序对接说明.md` 第 3 节）。建议对"底座+人格"这段固定内容开 **prompt 缓存**省成本。

## 三、核心设计速记（改之前先懂这几条）

1. **模型不预装剧情、无状态。** 它每轮的认知＝程序当轮喂的状态。剧情按节点喂（`node_text`），已得线索/规则当记忆——所以它**机制上无从剧透**（没拿到的就是没有）。
2. **三套系统能力不对称**（这是设计，不是 bug）：雀舌爱猜会坑、暖；乌有有危险直觉+程序弹窗；枢衡只给有把握的、常沉默。
3. **危险拦截只在乌有局**：唯一致命操作＝去井边，由**程序**弹固定脚本警告（不经过模型），且这句要**回灌进模型对话历史**保证记忆连续。
4. **侵染态**（清醒值<20）：回复失常、自由发挥；但**不出戏、不碰内容红线**这两条仍守。
5. **安全双层**：模型自身红线（prompt 里）+ **程序双向内容审核**（主防线，prompt 防不住的靠它）。
6. **恐怖留口子**：咬舌/跳井/幻觉是剧情氛围、允许；但不教现实自残方法、不仇恨歧视、不露骨色情、不碰现实政治人物。

## 四、改文件时的注意事项

- **改通用规则**（世界观、红线、输入输出格式、回溯等）→ 改 `Agent_System_Base.md` **一处**即可，三套系统同时生效。
- **改某个系统的性格/称呼/台词** → 改对应人格文件，**别动底座**。
- **底座里绝不要写系统名字**（雀舌/乌有/枢衡），否则会让系统串味。系统专属设定写在各自人格文件。
- **人格文件里别重复底座已有的规则**（如"不用括号描写动作""红线"这些底座写过了），只写该系统的差异。
- **示例台词**：是给模型"体会风格"用的，不是模板。文件里已写明"可贴合借用、但同一对话内不可重复套用"。换台词用挖空版填。
- **数值不要写死进 prompt**（积分/库存/恢复值等）——一律由程序按状态实时给，prompt/示例里的数字仅为示范。
