# 策划作品索引

这里保留《万象归墟》H5 版本的个人策划成果，便于同时投递 AI Agent 应用研发与游戏策划岗位。所有文件均保持原始格式，没有为了展示而改写或转换。

> 剧透提醒：`core/` 与 `agent/` 中包含完整剧情、复盘真相和角色行为规则。

## 目录

- `core/`：世界观、主线文本、道具、数值与人格设定等核心策划文档。
- `agent/`：随行 Agent 的 Prompt、协议、结构化数据和传参示例。
- `minigames/`：窃听、怪物追逐、倒茶玩法的设计表与可运行 H5 原型。
