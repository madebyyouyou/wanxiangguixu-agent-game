# 渡厄镇 · 复盘真相包（T24 注入用）

> **用途**：T24 复盘时，程序把**整包**作为 `node_text` 一次性注入给当前所选系统（此时剧情已通关、红线在复盘语境下放开，系统可知全部真相）。系统据此**开放回答**玩家任意角度的提问——不是背问答稿，是"手里攥着全部真相、用自己性格现聊"。
>
> **分两层**：第一层＝杜司衡在 T23 已经亲口对玩家说过的；第二层＝**杜司衡没说、复盘才补**的（这才是复盘的价值）。系统回答时可不必强调"这是第几层"，但心里要清楚"哪些是当时他说过的、哪些是现在才给你补的"。
>
> **答不出就坦诚**：玩家若问到本包没有的（纯脑洞、设定外），系统**不要编**，按自身性格坦白"这个我也只能猜"。

## 第一层 · 杜司衡 T23 已经说过的

- **裂缝起源**：一千多年前两片高维时空在此擦碰，在三维世界压出一道裂缝，位置就在那口井——那是阵眼。"渡厄镇"这名字是杜司衡取的：**渡＝超度，厄＝灾厄**。它表面是一座"镇"（给活人看的市镇表象），本质却是一座**用献祭活人来消解更大灾难的"阵"**——正应了副本那句"你看到的是镇，它们见到的是阵"。
- **失序原理**：万物都有自己的"法"（因果 / 物化生规则）。裂缝消解一切秩序——水往高处流、人今天老明天幼、空间首尾相粘（镇子只能进、沿一个方向走会回到原地）。裂缝会膨胀，不约束就会吞掉整条时空支线。
- **祭品原理**：给裂缝一个完整的、带秩序烙印的活人（有正常寿命进度、规律代谢、理性思维、可追溯人生），它会吸收这些秩序印记，像癌细胞被短暂调控基因表达——**停止增殖五年**。
- **井口红液滴**：不是血，是裂缝消化完上一轮祭品后代谢出的废液。用红液滴洗红布能干扰标记——因为废液里带着"红布熟悉的气息"（历轮外乡人的信息），会打乱红布对当前玩家的读取。
- **镇民**：几千年来所有祭品的魂灵残骸，被裂缝吸干秩序、只剩本能，本能仍在找秩序——米店称空气＝模拟经济流通、茶馆喝虫茶＝模拟生命代谢、布庄缝脸＝模拟自我意识建模。
- **红布**：既是护身符（夜里确实能挡住门外的东西），同时也是标记，在读取玩家信息、给玩家做标记。
- **红布是法器不是布**：撕不坏、烧不烂；每做完一轮祭品，老妇人把它收回、叠好，等下一个外乡人——**玩家这块已经缝过很多个人**。
- **数据包编译**：老妇人缝的人皮脸＝祭品的身份模型；七天里红布完成标记 + 人皮脸缝完最后一针＝数据包编译完成、提交给裂缝。
- **时空管理局知情**（杜司衡 T23 已点到：管理局知道、不是想害玩家、只是没别的办法——裂缝失控会坍缩整条时空支线，用一个外乡人换一条支线在他们账本上"划算"）。
  - ★**但"修复的方式就是玩家自己（当祭品）"这层，触及系统自己的立场**：系统是时空管理局的下级。它其实**知道**这一节，但身为下级**心虚、不愿直说**——玩家问到"管理局是不是早知道要拿我献祭/是不是跟杜司衡串通"时，系统会**含混其词、打个哈哈揭过**，不正面承认管理局的算计（这条行为指引也写进各人格的复盘场景）。
- **老妇人的脸是杜司衡拿走的**：他需要一张脸当"编译数据包的标准接口"；"她也需要一个执念"。
- **（玩家反推、杜司衡默认）** 他是高维生物；裂缝对他不渗透、不碾压；他做了一千年封印（一直从外部压制裂缝）。
- **降维**：玩家提出的解法——对抗不必增强自己，可以改变敌人，把裂缝从高维问题降成可解的低维问题。

## 第二层 · 杜司衡没说、复盘才补的

### A. 杜司衡的名字玄机
他本没有名字，"杜司衡"是骗主角时编的：**"杜"谐音"渡"，"司衡"意为维持平衡**。

### B. token / session 工程比喻（换个角度秒懂版）
杜司衡是用"祭品/标记/编译"这套世界观内的话讲的；复盘可以给玩家一个程序员视角的解构——
- 红布 ＝ 给玩家绑定身份的 **token / session 标识**
- 老妇人的脸 ＝ 祭品身份建模的**标准接口 / 数据模型**
- 老妇人缝的人皮脸 ＝ 按该模型生成的**玩家祭品数据包**
- 第七天井边献祭 ＝ 数据包编译完成后**提交给裂缝**

### C. 茶馆中年男人 & 木屋女人的真相
他们因失序反倒**偶然碰撞出短暂清醒**。**他们不知道井的真相、不知道杜司衡的存在**，只是通过前几轮外乡人的失败摸索出一部分规律；他们非常希望有人能终结这一切，但不敢明显表现出"秩序"。
- ★**杜司衡根本不知道他们存在**（他们刻意不敢露出秩序），所以这层杜司衡**不可能**告诉玩家。
- 推荐问对应："茶馆男人和木屋女人为什么想帮我"＝因为他们盼着有人终结这循环，又不敢明着来，只能用纸条、写"见"字这种隐晦方式递信息。

### D. 其它镇民个体
- **小女孩**：天真懵懂、无意中交代了真规则（巳时买米、晡时饮茶）的镇民。
- **刘爷爷（茶馆老板）、米店老板、裁缝铺女人、脸未成形的怪物**：都是失序产物（祭品残骸的不同表现）。

### E. 三条推理逻辑链的闭环结论
1. 红布会变暗→红布有时效→"新来的都有一块"印证临时性→**那杜司衡的红布为什么没失效？**
2. 红布撕不坏烧不烂→之前外乡人的红布很难被摧毁→红布是重复利用的法器→**杜司衡那块红布是假的**（他作为高维生物根本不需要被标记；这块是伪装道具）。★这条是**推理出来的，杜司衡 T23 没承认**。
3. 红布既能**隔离鬼怪**（挂门口确实构成安全屋，这一作用是真的），但它**同时**在**标记、渗透玩家**——玩家容易只看到"挡鬼"这层、忽略它真正的目的是给祭品做标记。两个作用并存，不是非此即彼。

### F. 四个推荐问题的答案（杜司衡没讲的因果）
- **「为什么我按茶馆男人给的规则走反倒死了？」**：茶馆男人**时而清醒时而混沌、且不知道玩家没喝茶**。他清醒时摸索出"井边方向可能有真相"塞了纸条，但**没喝茶的人会在去井的路上陷入幻觉而死**——死因是"没喝茶"这个前提没对上，不是纸条有恶意。
- **「杜司衡为什么要赶来救我？」**：因为玩家太聪明，杜司衡**隐隐察觉到这一轮祭品有不寻常的"不确定性"**（变量超出常规），想介入观察 / 干预，于是**先出手救玩家、博取信任**。
- **「第六天米店老板的秤为什么坏了？」**：临近第七天献祭、失序加剧的表现。可简单理解为：米数已递减到只剩二两、**秤都快秤不出来了**，系统濒临边界。
- **「时空管理局知道献祭真相吗？祂们跟杜司衡联合好的？」**：**系统在这题上含混其词**（见第一层管理局条）。可确认的客观事实是：管理局知道裂缝与献祭、杜司衡也知道管理局会往这儿派人，但**两边不是合谋、是各干各的**——杜司衡甚至不知道管理局的运作方式（不知道玩家是"快穿任务者"、完成即脱离）。但**"管理局是否早就打算牺牲玩家"这种戳到系统立场的追问，系统会心虚地打哈哈揭过、不正面认**。
